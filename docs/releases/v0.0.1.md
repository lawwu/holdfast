Holdfast's first installable preview for **Apple Silicon Macs running macOS 15 or later**.

### Download and install

1. Download the `.pkg` attached to this release.
2. Open it and follow the installer. Holdfast is installed in `/Applications`.
3. Open Holdfast, choose your notes folder, and download an answer model or connect
   Ollama, LM Studio, or a compatible model server.

This preview is unsigned and has not been notarized by Apple. If macOS blocks it,
review [Apple's instructions for opening trusted apps](https://support.apple.com/en-us/102445).
After attempting to open it, **System Settings → Privacy & Security → Open Anyway**
may be available for the installer or app. Only allow the download if you trust its source.

Node is bundled. The core app needs no Homebrew, Xcode, or separate Node installation.
Model weights are downloaded separately; the installer contains no personal notes or models.

### Included

- Search and cited answers over your notes and documents, with optional meaning search.
- LocalMLX as the default inference provider and optional model-server connections.
- Regular Pi for the agent loop; proposed edits wait for approval in the Inbox.
- Snapshots, exact Undo, stale-edit refusal, and local-only handling for private notes.
- The Paper & Pine interface and Markdown Quick Look preview.

### Preview limits

- Intel Macs are not supported by this installer.
- Recording-file and stream imports require the optional `ffmpeg` tool; video-link
  imports also require `yt-dlp`. These tools are not installed by the package.
- There is no automatic updater yet. Future versions will be available as GitHub release installers.
- Packaging, bundled-runtime operation, and approval/Undo behavior are tested with synthetic notes.
  A separate clean Mac has not yet been used for acceptance testing.

`SHA256SUMS` verifies the download. `release-manifest.json` records its source commit,
Node version, supported platform, checksum, and signing/notarization status.
