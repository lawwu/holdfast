# Holdfast v0.0.1

The first installable preview for Apple Silicon Macs running macOS 15 or later.

- Search your notes and ask questions with cited answers.
- Run AI locally with LocalMLX, or connect an existing model server.
- Review proposed edits in the Inbox and undo changes when needed.
- Preview Markdown notes in Finder with Quick Look.

Models download separately. Recording and stream imports require `ffmpeg`.
This version has no in-app updater.

This historical release is an **unsigned, unnotarized preview**. Use the
[latest signed release](https://github.com/lawwu/holdfast/releases/latest) for installation.
