# Holdfast v0.0.3

Bring your own LocalMLX model while keeping the recommended list and Inbox approvals.

**Your notes. Your Mac. Your control.** The README and documentation now lead with
Holdfast's default privacy promise: AI runs on your Mac and your notes stay local.
Choosing a server provider sends it your question and relevant note context;
protected notes stay with LocalMLX on this Mac.

## Add a model

Open **Settings → Answer → Change model… → Add model…**.

- **Hugging Face:** paste an `owner/model` repository ID or its main model URL.
  Holdfast checks metadata and architecture before adding it under **Your models**.
  Choose **Download**, then select it once the download finishes. Downloads use
  the source and access token in Settings → Downloads.
- **Local folder:** choose an existing MLX checkpoint. Holdfast uses the files
  where they are and saves the choice across launches. Removing a model from the
  list keeps its files on disk.

Custom models also appear in Ask's model menu once their files are available.
The recommended list remains available. File checks catch unsupported
architectures and incomplete checkpoints; they do not establish answer quality
or tool support. GGUF models can use an Ollama or LM Studio connection.

Holdfast still owns its tools, privacy checks, Inbox approvals, and Undo. A model's
proposed note changes wait for approval before anything is written.

## Install

Download **`Holdfast-0.0.3-macos-arm64-unsigned.pkg`** from the assets below.
Requires **Apple Silicon and macOS 15 or later**. The installer includes Pi and
Node; model weights download separately. Existing notes and model files stay in place.

This is an **unsigned, unnotarized prerelease**. Follow the
[installation guide](https://lawwu.github.io/holdfast/getting-started/) if macOS
blocks it. The [guided tour](https://lawwu.github.io/holdfast/tour/) and offline
walkthrough downloads remain available with this release.

## Validation

Local testing covered a real Hugging Face download and model load, adding an
existing model folder, persistence across app restarts, and a real local-model
edit through Pi. Inbox approval changed only the requested checkbox; Undo
restored the original file exactly, and an outdated proposal was refused.
The small downloaded model answered poorly, so loading successfully is not a
quality endorsement. Custom models are labeled unbenchmarked.

Automated checks cover model inputs, checkpoint completeness, cache links,
non-destructive removal, download sources, and the existing agent runtime.
GitHub's release workflow tests the packaged installer and approval behavior
without running real MLX inference in the cloud.
