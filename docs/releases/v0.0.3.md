# Holdfast v0.0.3

Bring your own LocalMLX model.

- Add a Hugging Face model or an existing model folder through **Settings → Answer → Change model… → Add model…**.
- Choose custom models from Ask's model menu. The recommended models remain available.
- Model checks catch unsupported formats and incomplete files; answer quality and tool support vary by model.

Proposed changes to notes still wait for your approval in the Inbox.

This historical release is an **unsigned, unnotarized preview**. Use the
[latest signed release](https://github.com/lawwu/holdfast/releases/latest) for installation.
