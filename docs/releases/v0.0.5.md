# Holdfast v0.0.5

Listen to YouTube and other video links.

## Listen to video links

In **Listen → A stream**, paste a link to a YouTube, Vimeo, Twitch, SoundCloud or
similar page. Holdfast fetches its audio with yt-dlp (`brew install yt-dlp`),
transcribes it on this Mac as fast as it downloads, and names the transcript for the
video. Radio streams, `.m3u8` links and files work as before.

A link or stream that can't be opened now says why, such as "This video is
unavailable" or "404 Not Found", instead of reporting that it heard no speech.

## Releases

GitHub Actions are locked to exact commits and checked with zizmor on every pull
request, and the release's publish step now runs on macOS, where it checks the
signed installer and disk image before uploading them.

## Install

Download **`Holdfast-0.0.5-macos-arm64.dmg`** and drag Holdfast to Applications, or
run **`Holdfast-0.0.5-macos-arm64.pkg`**. Requires **Apple Silicon and macOS 15 or
later**. Signed with Developer ID and notarized by Apple. Your notes, settings and
downloaded models stay in place.

## Validation

A short YouTube video transcribed correctly in a test copy of the app; an unavailable
video and a broken stream link gave their real errors. A live YouTube stream was not
tested. The release workflow signs, notarizes and tests the packaged installer
without running real MLX inference in the cloud.
