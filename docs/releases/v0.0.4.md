# Holdfast v0.0.4

Signed and notarized by Apple, with model management, comparisons and reranker choices.

## Signed and notarized

The installer and the disk image are signed with Apple Developer ID and notarized by
Apple. macOS opens them without a security warning or a trip to Privacy & Security.
Releases up to v0.0.3 were unsigned previews; install this one over them as usual.
Your notes, settings and downloaded models stay in place.

## Models

- **Models window** with Recommended, Downloaded, Browse and Downloads: grouped
  precision choices, memory guidance, disk use, reusable per-model settings, and a
  button to release a model's memory.
- **One download queue** for every model, with pause, resume, retry and recovery after
  a restart, and progress shown as percentage, speed and time remaining.
- **Reranker choices** in Search settings: Qwen3 0.6B (the default), 4B and 8B, each
  downloaded separately, with the choice remembered and switching handled safely.
- Optional **Parakeet Ultra and Redux** speech models, downloaded from the same mirror
  as the others.

## Asking and comparing

- **Chat attachments** stay local for that conversation; they are not imported or indexed.
- **Comparisons** run one question through several models in turn, with shared
  references, citations, timing and edit previews. Only previews you choose go to the
  Inbox; approval and Undo work as before.
- **File imports** keep each file's result visible, with links to review its proposal
  in the Inbox.

## Install

Download **`Holdfast-0.0.4-macos-arm64.dmg`** and drag Holdfast to Applications, or
run **`Holdfast-0.0.4-macos-arm64.pkg`**. Requires **Apple Silicon and macOS 15 or
later**. The installer includes Pi and Node; model weights download separately.

## Validation

The release workflow signs and notarizes the installer and the disk image, checks both
with Gatekeeper, and tests the packaged installer, Pi runtime, Inbox approval, exact
Undo and stale-edit refusal, without running real MLX inference in the cloud. Locally,
the model, comparison and reranker changes were tested on a sample vault. Transcription
with Parakeet Redux is not yet verified: its first load took more than ten minutes.
