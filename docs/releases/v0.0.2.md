# Holdfast v0.0.2

A friendlier introduction to Holdfast, with a narrated tour and illustrated documentation.

## Start here

- [Watch the guided tour](https://lawwu.github.io/holdfast/tour/): browse notes, ask a question, check a citation, approve an edit, and undo it.
- [Follow the getting started guide](https://lawwu.github.io/holdfast/getting-started/) with real app screenshots and fictional sample notes.
- Download `holdfast-tour.mp4`, `holdfast-tour.vtt` (English captions), and `holdfast-sample-notes.zip` from this release to follow along offline.

The walkthrough uses real app views and local-model responses. Waiting time is removed; it is not a real-time performance demonstration. Narration is generated with ElevenLabs. No personal notes are used.

## Install

Download `Holdfast-0.0.2-macos-arm64-unsigned.pkg` below. Requires **Apple Silicon and macOS 15 or later**. The installer includes Pi and Node; model weights download separately.

This remains an **unsigned, unnotarized prerelease**. macOS may block installation. See the getting started guide for Apple's instructions for opening a trusted app.

## Other changes

- Shorter README with a clear route to installation, the tour, and the full reference guide.
- Documentation and its screenshots live in this repository and deploy to GitHub Pages from published releases.
- Release publication verifies the walkthrough assets before uploading them alongside the tested installer.

Holdfast's tools, privacy checks, Inbox approvals, and Undo remain in the app. The documentation capture driver is compiled only in a separate local demo build and is absent from release builds.
