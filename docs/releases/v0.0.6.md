# Holdfast v0.0.6

Get future updates inside Holdfast.

- Use **Holdfast → Check for Updates…**, or turn on automatic checks in **Settings → Updates**.
- An **Update available** button shows when a new version is ready. Read what's new and choose when to install and restart.
- Download the latest DMG directly from the docs, with shorter release notes and fewer download choices.

Install this version manually once to enable future in-app updates. Your notes,
settings and downloaded models stay in place.
