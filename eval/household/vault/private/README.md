# Private — operating manual

Erik is in supervised training as a case reviewer through Hillcrest Bible Church.

## Confidentiality — read first

- **Initials only.** Participants and their family members are named by initials
  (D.M., K.M., R.S., T.S.), never full names, employers, addresses or other identifying details.
- If a document arrives with a full name in it, replace the name with initials before saving.
- Nothing here is shared outside the supervisor relationship.

## Files

| Path | What it is |
| --- | --- |
| `private/<initials>/` | One folder per participant, lowercase initials (e.g. `private/dm/`) |
| `private/<initials>/<initials>-session-NN.md` | One case report per session, in the 16-question case report form |
