# Ministry — operating manual

Erik is in supervised training as a biblical counselor through Hillcrest Bible Church.
His supervisor is Pastor J.; referrals come from the pastors (often Pastor R.).

## Confidentiality — read first

- **Initials only.** Counselees and their family members are named by initials
  (D.M., K.M., R.S., T.S.), never full names, employers, addresses or other identifying details.
- If a document arrives with a full name in it, replace the name with initials before saving.
- Nothing here is shared outside the supervisor relationship.

## Files

| Path | What it is |
| --- | --- |
| `counseling/<initials>/` | One folder per counselee, lowercase initials (e.g. `counseling/dm/`) |
| `counseling/<initials>/<initials>-session-NN.md` | One case report per session, in the 16-question case report form |

## Rules

  headings and the header line `Date: YYYY-MM-DD · Session: N · Length of Session: M minutes`.
